# HyperFileLens Reference Screenshots

This directory contains the 21 PNG screenshots supplied as design reference
evidence for the HyperOne integration prototype. They are reference material,
not runtime assets, and are not loaded by the prototype.

The UUID filenames are retained from the supplied reference set. Before using
an image in public documentation, review it at full resolution and confirm that
it contains no credentials, tokens, private keys, customer data, private
hostnames, internal IP addresses, tenant names, or other sensitive identifiers.

The screenshots are intentionally kept separate from the prototype directory so
the prototype remains self-contained and can be opened without them.
