# 网络配置 · 容灾创建 / 编辑

参照 HyperBDR 当前页面及 `newmuse` 源码制作的独立静态原型。
同一页面通过顶部两个导航项切换：

- **容灾配置**：创建流程的第 5 步“网络配置”。
- **网络配置**：已有主机的网络配置编辑页面。

不扩展其他创建步骤，不增加原页面以外的工具栏、说明区或网卡标签。
创建页的步骤条保留原布局，但只呈现第 5 步；取消、上一步和返回不跳转其他页面，
下一步只在本地校验并保存第 5 步，不进入第 6 步。

## 演练网络 / 接管网络

两个产品场景都在单/多网卡区块上方增加居中的用途标签，右侧为默认勾选的
“接管网络默认使用演练网络”。用途标签切换下方整个区块，而非只切换网络选择项。

- 默认进入演练网络；接管网络实时跟随演练网络的所有配置，包括单/多网卡方式。
- 继承期间可查看接管网络和详情，但不能切换网卡方式、编辑字段、勾选批量主机、
  批量设置、添加、修改或移除网卡。界面禁用控件，数据更新入口也有只读保护。
- 第一次取消继承时，深拷贝当前完整演练配置作为独立接管草稿。
- 再次启用继承不会丢弃独立接管草稿；再次取消时恢复原草稿，不重新覆盖。
- 主机范围与源端信息共用，目的网络的表单、网卡数量、模式分别保留。
- 用途切换不提交或重置配置；用途与产品场景切换均保留各自草稿。
- 整体保存时，继承模式只校验演练网络；独立模式分别校验两份网络，
  不会把不同用途下相同的地址当成重复地址。
- 保存格式升级为 `version: 2`，包含完整网络方案和继承标记；
  旧 `version: 1` 单网络草稿自动作为演练网络加载，默认开启继承，不丢失原配置。

### 场景帮助说明

演练网络和接管网络标题右侧提供 16px 线框问号及 26px 交互区域，交互参照 `newmuse`。
选中标签上的图标为白色线框，未选中时为深灰色；提示框使用深色背景与 14px 白色文字：鼠标悬停或键盘聚焦可查看用途、演练网络选择说明和接管连通性要求。
点击问号可固定/关闭说明；按 Escape、焦点离开或点击外部可关闭。
提示框可移入阅读，接管标签因继承而禁用时问号仍可使用，且不会切换场景或修改配置。
说明与无障碍名称均支持中英文，保留原有标签下方的简短描述。

## 中英双语

点击右上角原有语言图标，在“简体中文 / English”之间切换。
语言偏好单独保存在本地，刷新后保留；不会提交、重置或翻译业务配置值。
创建/编辑、演练/接管、单/多网卡、批量弹窗、网卡抽屉、规则详情、提示与校验均支持切换。
打开弹窗或抽屉时也可切换，未提交的 IP、带宽、安全组等草稿与滚动位置保持不变。

- `translations.js`：复用 `newmuse/src/lang/zh.js` 与 `en.js` 的 **90 项**对应条目，
  中英文值逐项保持原样，使用原有键名，并通过 `UI_MESSAGE_SOURCES` 记录来源。
- `prototype.*`：只补充新用途标签、继承开关、原型专有校验及无障碍名称等原项目没有的条目。
- `i18n.js`：轻量语言字典、参数插值、静态标签更新、语言菜单与偏好存储。
- 全部语言资源在本目录内，无 Vue、VueI18n、CDN 或运行时跨目录依赖。
- 主机名、网络名、安全组名、资源 ID、IP 等作为数据保留，不会被语言切换改写。
- 英文针对较长的步骤名、IP 模式与表单标签调整布局，中文保持原页面风格。

## 文件

- `index.html`：语义化页面结构、场景导航、步骤条、页签、表单和表格。
- `styles.css`：页面、批量弹窗、下拉菜单及网卡抽屉样式。
- `app.js`：场景独立状态、本地模拟数据、联动、批量设置、网卡操作与动态本地化校验。
- `translations.js` / `i18n.js`：本地双语条目及切换逻辑。
- `assets/`：从 `newmuse` 复制的 Logo 与原有图标，无跨原型依赖。
- `interactions.test.mjs`：直接执行实际应用代码的逻辑与结构测试。

主要节点包括 `creation-configuration-steps`、`single-network-form`、
`network-purpose-switcher`、`network-purpose-content`、
`takeover-use-drill-network`、`creation-batch-actions`、`single-hosts-table`、`multiple-hosts-table`、
`batch-network-dialog`、`target-nic-editor` 和 `nic-security-group-table`。
动态行提供 `data-host-id`、`data-nic-id`、`data-primary` 与 `data-batch-select`。

## 运行

直接打开 `index.html` 即可，无框架、构建步骤或外部服务依赖。
也可在原型仓库根目录运行 `npm run serve`。

- `index.html#create`：直接打开创建页第 5 步。
- `index.html#edit`：直接打开编辑页。

## 交互

### 创建场景

- 与当前真实页面一致的两台主机：`ZhangTianJie-TestSync5` 和 `ZhangTianJie-TestSync2`。
- 单网卡表格支持全选、部分选择；有选中行时启用三种批量设置。
- 批量内网 IP 设置模式，具体 IP 留在主机行内单独填写。
- 批量公网 IP 根据分配方式动态显示申请带宽输入。
- 批量安全组只作用于选中的主机。
- 多网卡分别限制为 12 块和 2 块，与真实页面当前主机规格一致。

### 两种场景共用

- 单网卡 / 多网卡切换，分别保留草稿。
- 网络 / 子网联动，IP 分段输入，公网 IP 与共享带宽模式切换。
- 安全组选择、规则查看、已选主机只读抽屉。
- 网卡添加、修改、移除；主网卡不可移除。
- 抽屉修改只有点击确定后应用，关闭抽屉不影响原数据。
- IPv4、子网范围、重复地址、带宽与必填项校验。
- 两个场景及其本地保存相互隔离，切换不会覆盖另一场景的配置。

全部数据与保存都在本地，不访问真实后端，不修改云平台资源。
示例公网 IP 使用 RFC 5737 文档地址。
