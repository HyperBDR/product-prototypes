✦安装 HyperBDR skills让智能体安全调用 HyperBDR

安装 HyperBDR skills 后，支持的智能体可以理解 HyperBDR 的资源、容灾和运维操作。请先完成安装，再使用下方的 CLI Access Token 连接当前租户。

1

安装 skills

在智能体所在环境执行安装命令，完成 HyperBDR 工具能力注册。

2

配置访问令牌

创建一个有明确有效期的 CLI Token，仅在生成时复制一次明文。

3

开始使用

重新打开智能体会话，让它发现 HyperBDR skills 并访问业务接口。

安装命令
npx skills add hyperbdr
