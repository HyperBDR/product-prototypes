# SourceLens 全站交互原型（多租户治理版）

基于 `main@f252b5d6` 的页面清单设计。**纯设计稿，未改动仓库任何代码。** 52 个页面 · 144 个边界场景 · 桌面 + 手机 · 浅色 / 深色。
治理逻辑见同目录 `治理地图.html`（角色 / 资源归属 / 权限矩阵 / 环境变量三层 / 超管职责与代管）。旧的单租户版备份在 `../全站原型-v1备份/`。

## 打开方式
- `python3 -m http.server -d 全站原型 8800` 后访问 http://localhost:8800 ，手机可访问同一地址真机预览；也可直接双击 `index.html`（需联网加载字体，离线会回退系统字体）。
- 改完文件后请强制刷新（Ctrl+Shift+R），浏览器会缓存脚本。

## 角色与三个区域
租户内只有两种角色，另有平台超管：
| 角色 | 能做什么 |
|---|---|
| 普通用户 | 只使用助手（对话、历史），管理自己发出的分享；无任何管理入口 |
| 租户管理员 | 管理本租户一切：知识库与同步、模型、成员与用户组、审核分享、查看运行与用量 |
| 超级管理员 | 平台级：全局统计、租户创建与代管、共享节点、官方目录、平台自用模型、平台告警与通知、任务、全局配置 |

- 只有一个侧栏。进入管理区的入口在**左下角用户名点开的菜单**（租户管理 / 平台控制台 / 返回对话）。
- 三个区域：**工作台**（对话）· **租户管理**（左栏浅蓝渐变）· **平台控制台**（左栏浅紫渐变，仅超管）；右侧均为白底。
- 超管**代管租户**：在「租户与代管」点「进入租户」，顶部出现红色代管提示条；可帮租户配置模型 / 节点 / 知识库 / 助手等；**成员、用户组、角色在代管模式下不可见**（由租户自己控制）。
- 无权限直接打开页面时显示「你的角色无权访问」。

## 菜单
- **租户管理**：概览（管理概览、配置向导）/ 助手(Assistant)管理（助手、问答历史、助手评估、QA 榜单审核、环境变量）/ 知识库管理（知识库）/ 插件管理（能力市场、连接）；能力市场内含 全部、技能、MCP、连接器 四个标签（全部 / 技能 / MCP Servers / 连接器）/ 租户管理（租户信息、成员管理、组管理、API Key）/ 大模型管理（使用统计、使用明细、模型配置）/ 通知管理。沿用原菜单顺序，默认全部展开、可折叠。
- **平台控制台**（超级管理员只做平台运营与运维 + 全局 / 租户维度的统计与可观测；**默认不管理租户内容，也没有租户切换下拉**，租户内的事通过「租户与代管 → 进入租户」代管）：**全局概览**（独立一级）/ **租户管理**（租户与代管、租户统计、成员总览、API Key 总览——泄露排查与成员归属都能从全局搜到）/ 节点管理（节点、节点设置）/ 官方目录（技能、MCP Servers、连接器，各自独立、保持展开）/ 大模型管理（使用统计、平台模型配置、历史记录清理设置）/ 告警与通知设置 / 任务管理 / 审计与配置（审计日志、全局配置）。
- 不在菜单里但可从控制条打开：发送统计 / 发送明细 / 通知设置 / 消息发布、助手评估详情 / 报告。

## 通用交互规范（落地时请保持一致）
- **列表**：分段（状态）+ 搜索 + 筛选 + 批量栏 + 分页；行内操作统一“…”菜单；手机端自动卡片化（首列为标题）。表格区域用小圆角（8px），表头透明、行高约 56px、表头可固定。
- **详情 / 创建 / 编辑 / 导入 / 批量操作**：统一右侧抽屉（手机全屏，桌面直角贴边）；多步用步骤条。只有危险操作二次确认保留居中对话框。
- **危险操作**：二次确认，写明影响面（受影响的助手 / 租户 / 分享 / Run 数量）；不可逆操作要求输入确认词。
- **状态**：加载=骨架屏；失败=原因+request_id+重试；无权限=说明缺什么+申请入口；离线=顶部横幅+只读缓存。
- **空状态**：说明“这是什么 / 为什么没有 / 下一步”，并给主操作按钮。
- **市场样式**（技能 / MCP / 连接器）：已启用 → 热门 → 新品推荐，卡片右侧一键 +；官方内容“启用即用”，不复制。

## 已知简化（原型层面）
- 数据均为确定性假数据；写操作仅给 toast / 状态反馈，不持久化。
- 每页的“设计说明”基于读代码与 locale 推断，不是对线上界面的逐项核对。
- 聊天的 @ 引用选择器、文件预览、附件上传、助手表单的全部字段为示意。
- 图表为 SVG 示意，真实图表库的交互（缩放 / 刷选）未覆盖。
- 额度 / 计量功能未上线，原型中不出现。
- 官方目录里的模板数据为示意，真实模板来源与分类需后端确认。
