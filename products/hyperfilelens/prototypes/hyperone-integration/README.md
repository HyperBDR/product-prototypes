# HyperOne Integration Depth

This static build presents four neutral integration proposals for combining
HyperFileLens, HyperBDR and HyperCDR under the HyperOne concept name:

- A — product switching
- B — entry integration
- C — observation handoff
- D — in-place operation

Use the proposal selector in the prototype to compare overview organization,
execution lists, object details and write-operation boundaries. All data and
operations are local fictional samples. The prototype does not call a backend,
store credentials, or represent a production integration.

Reference screenshots are stored separately at
`references/hyperfilelens/screenshots/` in the repository root.
